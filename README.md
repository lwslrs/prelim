# Valentine's Letter Component

A cute React component that showcases an interactive Valentine's letter with animations.

## Features ✨

- 💌 Cute envelope that opens on click
- 💕 Love letter slides up with romantic message
- ❤️ Floating hearts and flowers animation
- 🌸 Smooth transitions and CSS animations
- 📱 Responsive design with Tailwind CSS

## Setup

```bash
npm install
npm start
```

The app will open at `http://localhost:3000`

## Project Structure

```
src/
├── App.js
├── index.js
├── index.css
└── components/
    └── ValentineLetter.js
```

## How to Enhance It

- Add random love quotes on each open
- Personalize with recipient's name via props
- Add background music
- Implement confetti animation with framer-motion
- Create multiple letter templates

## Technologies Used

- React 18
- Tailwind CSS
- CSS Animations
