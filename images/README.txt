IMAGES FOLDER - Instructions
=============================

Please place your images here:

1. couple-photo.jpg - The photo that appears in the upper right when the envelope opens
   (This should be the couple photo you already shared)

2. center-image.jpg - The image that will appear in the center of the letter
   (Place the second image you want to show here)

After adding the images, the app will automatically display them!

Note: Make sure the file names match exactly:
- couple-photo.jpg (for the upper right photo)
- center-image.jpg (for the center photo)

You can also use .png format if needed, just update the file extensions in:
src/components/ValentineLetter.js
